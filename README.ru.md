# Bridge Commander

Свой MCP-сервер для работы ИИ-ассистента (Claude Desktop, Claude Code, коннекторы ChatGPT, любой MCP-клиент)
с файлами, поиском, терминальными сессиями и процессами — на этом компьютере и на других узлах через SSH.

Зависимостей кроме стандартной библиотеки Python нет. Используйте поддерживаемую версию Python 3.12 или новее; совместимость исходников также проверяется на 3.9. Клиент собирается в один файл `bridge-commander.pyz`.

Для бесплатной беты ChatGPT используйте [Bridge Commander Cloud](https://bridgecommander.dev) и [порядок подключения](README.md#hosted-cloud-no-server-of-your-own). Новая настройка открывает только чтение папки `~/BridgeFiles`. Apple Developer для плагина и Python-клиента не нужен. Контакт — Support: support@bridgecommander.dev.

## Быстрый старт

```bash
python3 scripts/build_pyz.py                 # -> dist/bridge-commander.pyz
python3 dist/bridge-commander.pyz init       # создаёт ~/.config/bridge-commander/config.json
claude mcp add bridge-commander -- python3 /полный/путь/bridge-commander.pyz serve
```

## Что умеет

- **Файлы:** чтение (текст, изображения, Word .docx, Excel .xlsx, PDF, адреса http(s), диапазоны строк, хвост), запись и дописывание, точная замена
  фрагмента `edit_block`, перемещение, создание каталогов, сведения о файле.
- **Поиск:** по имени или маске (`*.py`), по содержимому (регулярное выражение или текст, с контекстом);
  фоновый поиск с постраничной выдачей для больших каталогов.
- **История:** последние вызовы инструментов и статистика из журнала.
- **Терминал:** долгие и интерактивные команды с постепенным выводом и вводом (`start_process`,
  `interact_with_process`, `read_process_output`, `force_terminate`, `list_sessions`).
- **Процессы:** список и завершение системных процессов.
- **Узлы:** один сервер-хаб пересылает вызовы на другие машины (`node`), где работает `bridge-commander worker`.
  Правила каждого узла (разрешённые каталоги, только чтение, запрещённые команды) применяет сам узел.
- **Доступ:** stdio для локальных клиентов и по SSH; HTTP с обязательным токеном для ChatGPT/claude.ai через туннель.
- **Защита:** разрешённые каталоги (символьные ссылки не выводят за их пределы), режим только чтения,
  список запрещённых команд, лимиты размера и вывода, журнал вызовов JSONL.

## Безопасность

Это удалённый доступ к командной строке. `allowedDirectories` ограничивает файловые инструменты, но команда,
запущенная через `start_process`, работает со всеми правами пользователя. Используйте отдельного пользователя,
`readOnly` там, где нужно только смотреть, и держите HTTP на 127.0.0.1 за туннелем с токеном.
Подробно — [docs/SECURITY.md](docs/SECURITY.md), удалённый доступ — [docs/REMOTE.md](docs/REMOTE.md).

## Проверки клиента 1.3.0

Чистый код клиента прошёл 80 проверок на macOS; на Linux — 79 и один пропуск необязательного PDF-конвертера. Отдельно проверен реальный Linux-клиент через публичный HTTPS: письмо входа, подтверждение устройства, OAuth, чтение/поиск, разрешённая запись, защита от повторения и отзыв доступа. Это не проверка нового чата ChatGPT или приложения iPad. Публичный маршрут облака — OAuth https://bridgecommander.dev/mcp.

PDF: `pdftotext` (poppler), если установлен, иначе встроенный в macOS PDFKit. На Windows для PDF нужен poppler
(сборка poppler для Windows с папкой `bin` в PATH, например `scoop install poppler`); остальное работает на одном Python.
